# Curation ledger — the existing body, judged by eye

Curation is not just new work. Every existing piece is judged against
DESIGN_RUBRIC.md (incl. no-schematics + depth). Verdicts from direct viewing.
KEEP = gallery-ready. REWORK = good bones, fails ≥1 dimension. KILL = the
concept itself can't be art (schematic/redundant).

## Process

Every REWORK goes through the studio critic panel when agents are back (10am).
KILLs are deregistered but code is kept (version history). This ledger updates
as pieces are re-judged.
